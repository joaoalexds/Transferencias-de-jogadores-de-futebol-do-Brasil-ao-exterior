# 📂 Dados Brutos (Raw Data)

Esta diretorio está reservado para o armazenamento dos ficheiros de extração originais (dados brutos) utilizados no processamento do pipeline, como os ficheiros HTML das páginas web.

## ⚖️ Fonte e Créditos dos Dados

Todos os dados originais utilizados e processados na construção desta análise de redes complexas foram extraídos e pertencem inteiramente ao **[Transfermarkt](https://www.transfermarkt.com.br/)**.

A extração e utilização destas informações foram realizadas com fins estritamente académicos, de estudo e demonstração de portefólio em Ciência de Dados, respeitando a plataforma original e os seus direitos sobre os dados.
